What changed since the last version

We measured the real timing. A coin is minted about two to four minutes after the post it came from, so nobody beats the bots to it and the old claim — that we surface a story before any coin exists — is not true for the coins that make money. But a coin takes about six days to peak, and one meme spawns hundreds of copies. So the claim that survives is stronger and harder to copy: we tell you which of those coins is the real one, while it is still climbing.
