  1. User triggers deploy from trending card, rail launch, or Create in Narratives/Trending mcap column.
  2. openDeploy(idx) or openDeployForNarrative(id) — edits coin name, ticker, first buy (0 / 0.5 / 1 / 2 SOL).

  4. deployFiled() → mkToken() → pushes to TOKENS, removes PENDING entry, refreshes all list views.
  5. Success modal shows contract address + Trade shortcut → openToken(sym).
